# AZ CLI Typing Practice

A typing-based flashcard app for practicing Azure CLI commands. Read the description, type the full command with flags, and get character-by-character feedback as you go.

## Features

- 200 commands across 16 categories including AKS, ACR, Key Vault, Pipelines, RBAC, Bicep, and more
- Character-by-character highlighting — green for correct, red for incorrect
- Filter by category to focus on specific areas
- Rank system that progresses from Intern to 10x Developer as you complete cards
- Progress saved to localStorage — pick up where you left off
- Skip cards to send them to the back of the deck
- Hide answer mode for users who want to type from memory

## Categories

Auth, Resource Groups, VMs, Networking, Storage, App Services, Functions, Container Instances, ACR, AKS, Key Vault, Service Bus, Pipelines, RBAC, Managed Identity, Monitor, App Config, Redis, SQL, IaC, Misc

## Running Locally

No install or build step needed. Just open `index.html` in your browser.

## Tech

Vanilla HTML, CSS, and JavaScript — no frameworks or dependencies.
